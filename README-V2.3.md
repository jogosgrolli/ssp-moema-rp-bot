# SSP Moema RP Bot V2.3

## Novidades
- Transferência funcional no Painel do Comando.
- Militar só transfere para Militar.
- Civil só transfere para Civil.
- Federal só transfere para Federal.
- Transferências entre estruturas são bloqueadas.
- A patente é mantida durante a transferência.
- A transferência gera LOG, DM ao membro e registro no requests.json.
- Mantidos os banners da Central de Registro e Central de Atendimento.
